# Competitive benchmark

This matrix is a capability comparison, not a marketing scorecard. Competitor observations are based on public product documentation reviewed on 2026-10-06.

Lovable describes prompt-to-working-app generation with UI, data, logic, authentication and hosting, plus security scanning; its mobile builder page describes mobile web/PWA rather than App Store/Google Play packages. Bolt describes a browser IDE, full-stack generation, responsive output and one-click deployment. Replit Agent describes prompt-driven app building, built-in database/auth, web research, deployment and broad framework support. v0 describes natural-language code/UI generation and deployment through Vercel. Figma Make describes prompt-to-app prototypes/web apps, web grounding, team collaboration, publishing and GitHub export. Cursor Agent describes codebase search/editing, terminal use, browser testing and long-running cloud agents that can create PRs.

Build Vibe does not claim parity where the repository has no executable contract. Its differentiation in this repository is the verification-first control plane: generated output is distinct from verification, target execution and deployment; missing external infrastructure is surfaced as BLOCKED or NOT_CONFIGURED; agent work is bounded, auditable and provenance-aware.
