# Code of Conduct

## Our standard

Build Vibe contributors are expected to communicate respectfully, review changes on their technical merits, protect user data, and keep security and verification concerns explicit.

Harassment, discrimination, doxxing, credential exposure, malicious repository content, or attempts to bypass security/release gates are not acceptable.

## Reporting

For security issues, use the private process documented in `SECURITY.md`. For non-security conduct concerns, contact the project maintainer privately rather than posting sensitive details publicly.

## Enforcement

The project maintainer may remove content, restrict participation, or reject changes that violate this code or endanger users.
